## 🍔 Slider Food — Galería de Platos Animada
Este proyecto consiste en una galería interactiva y animada de platos de comida, presentada con un slider horizontal. Es ideal como sección destacada para sitios de gastronomía, restaurantes o e-commerce culinarios.

## 🧩 Funcionalidades
  
  - Slider animado con transición suave
  - Visualización destacada del plato seleccionado
  - Efecto hover interactivo
  - Diseño responsive adaptable a dispositivos móviles
  - Navegación por botones o swipe
  
## 🧰 Tecnologías Utilizadas

  - HTML5
  - CSS3 (con transiciones)
  - JavaScript puro (sin frameworks)
  - Google Fonts
